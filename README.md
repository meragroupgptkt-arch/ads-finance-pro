## Deploy on Vercel

Upload the contents of this folder to the selected GitHub repository, then import that repository in Vercel.
Framework preset: Other. Build command: empty. Output directory: `.`.
If this folder is kept inside a larger repository, set Root Directory to `vercel-deploy`.

## Data storage

This version uses browser localStorage. Data is specific to each browser and origin; it is not shared across users or devices.
Export a backup in the original application and restore it on the deployed URL to transfer existing data.
Client-side role selection is not server-enforced authentication.
No POSCake API credentials are included in this deployment package.
